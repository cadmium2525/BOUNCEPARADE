# BOUNCE PARADE（バウンスパレード）

> 跳ねろ。変われ。突破しろ。

スマートフォン横画面向けの 2D 横スクロール物理アクション。プレイヤーはボールに変身し、サイズ・重さ・反発・形・特殊能力を使い分けてゴールを目指します。
`devkit/` の企画書・実装指示書（BOUNCE_PARADE_DevKit v1.0）をもとに、ブラウザで動くゲームとして実装しました（ビルド不要・HTML5 Canvas・ES Modules）。

## あそび方

- **公開**：GitHub の Settings → Pages で `main` / `(root)` を公開すると、スマホのブラウザでそのまま遊べます。ホーム画面に追加すると全画面・オフラインで動きます。
- **ローカル**：`python3 -m http.server` → `http://localhost:8000`

| 操作 | スマホ | キーボード |
|---|---|---|
| 空中の向き | 左パッド ◀ ▶ | ← → / A D |
| 高く跳ねる（押下長で 0.72→1.2 倍） | 左パッドを上へ、または右の ▲ | ↑ / W / Space / Z |
| 小さく跳ねる（0.5 倍） | 左パッドを下へ | ↓ / S |
| 変身（空中・地上どちらでも） | 右のボールボタンをタップ | 1〜6、Q / E で順送り |
| ポーズ | 右上 ‖ | Esc / P |

## 収録内容

- **ステージ 8**：はじまりの丘（チュートリアル）／工場／天空都市／火山／遊園地／地下鉱山／氷雪城／パレードタワー（最終）
- **ボス 6 体**：ドリルライノ、ストームクラウド、マグマゴーレム、バンパースパイダー、モグドリラー、フリーズキング（`Telegraph → Attack → Recovery → Vulnerable → Reset`、HP 半分で Phase2）
- **ボール 18 種**：初期 3 種（サッカー・ビー玉・ピンポン）＋ボス報酬 6 種（ボウリング・シャボン玉・火の玉・ラグビー・磁石・スライム）＋最終ステージクリアで追加 9 種
- **敵 6 種**：コロボット／ガチガチ（装甲＝ジャンプ台）／フワドローン／プルン（倒せないジャンプ台）／トゲマル／ポンポン砲（弾を反射）
- **ギミック**：発射装置（横・上）、重量壁・重量床、プレス機、バネ、バンパー、送風機、スイッチと扉、重量スイッチ、動く床、すり抜け床、トゲ、溶岩、氷、磁気レール、溶ける氷塊、強制区間（指定ボール区間）、チェックポイント
- **象徴コンボ**：サッカーで跳ぶ → ビー玉で小穴へ → 発射装置で射出 → 出口でボウリング球 → 重量壁を破壊 → サッカーで脱出（チュートリアルと最終ステージ）

## 仕様の実装メモ（実装指示書との対応）

- 物理は固定 60Hz、描画は補間。速い球はサブステップで移動（1 回の移動量 ≤ 半径の半分）してトゲや薄い床をすり抜けない。
- 世界単位（px）とスプライト表示を分離。ボールの見た目はアトラスの各セルの不透明部分を自動計測してコライダー半径に合わせる。
- ラグビー球はカプセル近似（5 円）＋角速度の剛体応答で、不規則に跳ねる。
- 変身：CD 0.12 秒、CD 中のタップは最新 1 件を予約（最長 0.5 秒）、同じボールは CD を消費しない。大きい球へは壁に重ならない位置を探し（押し出し経路も検査）、無理なら予約、0.5 秒で失敗表示。速度は維持。
- 静止した非反発球から反発球に変身すると、次の固定ステップで最低バウンドが入る（詰み防止）。
- 強制区間は CD 無視・手動切替不可、出たら CD リセット。強制区間はすべて「止まっても抜け出せる」形にしてある。
- 被弾：HP 3、1 ダメージ、無敵 1.2 秒、軽いノックバック。落下は 1 ダメージで直前の安全地点へ。HP 0 でチェックポイントから再開。
- 所持が 6 種を超えると出発前に最大 6 種を選ぶ（サッカーは常に装備）。
- 進行は `localStorage` に保存。

## BGM・効果音

すべて [かなでる](https://github.com/cadmium2525/mp4mp3)（`daw/`）で制作しています。

- `audio/src/bgm/*.json`・`audio/src/se/*.json` … かなでるの曲・効果音 JSON（アプリの「JSON を貼り付け」でそのまま開いて編集できます）
- `tools/sound/gen.mjs` … 上の JSON を作るスクリプト（作曲内容はここ）
- `tools/sound/build.mjs` … かなでるのエンジン（`daw/tools/render.mjs`）で音にして `audio/bgm/*.mp3`・`audio/se/*.wav`・`audio/manifest.json` を作る

```sh
git clone https://github.com/cadmium2525/mp4mp3 ../mp4mp3
node tools/sound/gen.mjs
KANADERU=../mp4mp3/daw node tools/sound/build.mjs        # 一部だけなら: ... build.mjs boss coin
```

BGM は 3 周ぶん描画して 2 周目をループ区間として切り出しているので、リバーブの余韻ごと継ぎ目なくループします（ループ位置は `audio/manifest.json`）。

## アセット

- `assets/atlas/balls_atlas.png` … キット同梱のボールアトラス（6×3、各 128px）。**差し替え用のプロンプトは [docs/ball_atlas_prompt.md](docs/ball_atlas_prompt.md)**。1 球ずつ生成した画像は `python3 tools/pack_balls.py <フォルダ>` でアトラスにまとめられます。
- 敵・ボス・ギミックはキットの画像が仮のアイコンだったため、`js/art.js` でコード描画しています。

## 構成

```
index.html / css / sw.js / manifest.webmanifest
js/
  main.js      起動・ループ・入力
  ui.js        タイトル／ステージ選択／装備／図鑑／設定／プレイ HUD／結果／エンディング
  game.js      1 ステージの進行（DOM 非依存・Node で動く）
  player.js    BallController（状態・変身・反発・吸着・磁石など）
  physics.js   円（とカプセル）とタイル・動く固体の衝突
  level.js     タイルマップとステージ用ビルダー
  stages.js    全ステージの地形
  entities.js  敵・ギミック・弾
  bosses.js    ボス 6 体の状態機械
  render.js    タイル・背景・ボール描画
  art.js       敵・ボス・ギミックの手続き描画
  audio.js     Web Audio（ループ区間つき BGM、効果音）
  balls.js     ボールの性能（データ駆動）
assets/  atlas・データ JSON（キットからコピー）
audio/   BGM・効果音・かなでる JSON
devkit/  BOUNCE_PARADE_DevKit v1.0（企画書・仕様書・原本素材）
tools/   テスト・音声ビルド・アトラス作成
```

## テスト（開発用）

```sh
node tools/test_physics.mjs    # 跳躍高さ・変身・静止からの復帰
node tools/test_combo.mjs      # チュートリアルを自動操作でクリア（象徴コンボ）
node tools/test_sections.mjs   # 各ステージの強制区間・発射装置を通過できるか
GOD=1 node tools/test_bosses.mjs  # 初期 3 球だけで 6 ボスを倒せるか（簡易ボット）
```

開発用 URL：`?stage=factory`（ステージ直行）、`?map=factory`（ステージ全体図）、`?unlock=1`（全解放）。
