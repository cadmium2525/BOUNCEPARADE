# BOUNCE PARADE — Development Kit v1.0

日本語の企画書・実装指示書と、全18球の透過PNGアトラス／JSON、通常敵6種・ボス6体・ギミック8種の**初期プレースホルダー**を収録したプロトタイプ着手用キットです。

## 重要
- `01_Planning/concept_board.png` はビジュアル方向性を示す**生成イメージ**です。ゲームから直接切り出せる正確なスプライトシートではありません。
- `03_Ball_Atlas/balls_atlas.png` は独立した透過スプライトを並べた**読み込み可能な初期版**で、`balls_atlas.json` に各領域の座標があります。18球とも1フレームで、アニメーション・回転差分は未収録です。
- 敵・ボス・ギミックの画像は**仮の単一フレームアイコン**です。完成版のキャラクターアニメーションではありません。
- 当たり判定の数値、速度、HP、CDは初期案であり、実機調整が必要です。
- 企画の18球すべてを画像化していますが、推奨実装順は初期3球、報酬6球、追加候補9球です。

## 読み込み
各アトラスのJSON `frame`（x,y,w,h）はピクセル座標。画像をテクスチャとして読み込み、source rectangleで切り出す。コライダーは画像輪郭ではなく物理データから生成する。画像表示縮尺はコライダーのゲーム内半径と整合するよう別途設定。

## ライセンス・注意
本キットの独自生成素材をプロジェクト検証用に利用できます。画像は初期版のため美術品質・エンジン別導入・商用配布前のQAが必要です。
